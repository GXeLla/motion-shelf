TEAM AGREEMENTS

Rules

A shared way of keeping ideas visible, changes traceable, and the codebase safe.

  1. 1

    Add every task idea

    Add a task whenever you have an idea, even if you think it may be a bad one. We will reconsider it together.

  2. 2

    Push each change before starting work

    Even when you assign a task, push that change to GitHub before you start working so everyone can see the progress and what you are working on.

  3. 3

    Protect the flow

    If you think a change could break something, create a new branch and test it there. Then push it and merge to master once it is safe.
